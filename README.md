GoNow Frontend

GoNow 앱의 프론트엔드 프로젝트입니다.
Expo 기반으로 개발되었습니다.

실행 방법
1. 의존성 설치
npm install
2. 앱 실행
npx expo start

실행 옵션
실행 후 아래 방법 중 선택하여 앱을 확인할 수 있습니다:
Expo Go 앱으로 QR 코드 스캔
Android Emulator
iOS Simulator (Mac 환경)

프로젝트 구조
app/        # 화면 및 라우팅 (Expo Router 기반)
assets/     # 이미지 및 정적 파일

개발 환경
Node.js
Expo
